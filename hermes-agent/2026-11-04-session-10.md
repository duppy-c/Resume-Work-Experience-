### 09:48-09:55 | Password login disabled

- Before: `sshd -T` showed permitrootlogin without-password, pubkeyauthentication yes, **passwordauthentication yes**, kbdinteractiveauthentication no.
- `/etc/ssh/sshd_config.d/` contained only `50-cloud-init.conf` (root-readable only) with `PasswordAuthentication yes` (from initial card setup). Main config line 12: `Include /etc/ssh/sshd_config.d/*.conf`.
- Verified rule (sysadmin article): sshd keeps the **first** value it reads; drop-ins load in alphabetical order. Created `00-keys-only.conf` so it beats `50-cloud-init.conf`.
- `sshd -t`: no errors. Reloaded ssh (current session stayed open).
- After: **passwordauthentication no**, pubkeyauthentication yes.
- Proof: password-only login attempt returned **"Permission denied (publickey)."**

```
cat ~/.ssh/id_ed25519.pub | ssh duppy_coder@<Pi address> "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

sudo sshd -T | grep -Ei 'passwordauthentication|kbdinteractiveauthentication|pubkeyauthentication|permitrootlogin'

```
