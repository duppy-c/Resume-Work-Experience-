#### 16:45 | Method documented: init=/bin/sh password reset

- **Name:** init=/bin/sh password reset, also called "booting to a root shell" or a "single-user mode bypass."
- **How it works:** Linux normally starts `init` first, which runs the login screen. Adding `init=/bin/sh` to the boot command line (`cmdline.txt` on a Pi) starts a root shell instead, with no password.
- **Category:** physical access attack (offline).
- **Defenses:** full-disk encryption; physical security; bootloader passwords / Secure Boot (on PCs that support them).
- **Lesson:** physical access usually means full access.
- **Steps (not yet performed):**
  1. On PC: back up `cmdline.txt` on the card's boot partition; append ` init=/bin/sh` to the single line.
  2. Boot the Pi to the `#` prompt; then:

```
mount -o remount,rw /
passwd pi
sync
```

  3. On PC: remove `init=/bin/sh` (or restore the backup); boot normally.

*Verification:* Steps from raspberry.tips (Raspberry Pi OS); not verified on Parrot specifically.
