## 1. Summary

- **ufw was already installed and active** on Parrot: deny incoming, allow outgoing, no rules. The expected default ("inactive") was wrong, so the real state was checked first.
- A test web server (port 8000) was scanned with the firewall **on → off → on + allow rule → rule removed**.
- **Tool anomaly found and solved:** iSH's nmap reports *closed* ports as **filtered**. This was proven with `nft` (no hidden firewall) and `curl` (refused vs. timed out).
- **Defense-in-depth lesson:** after the rule was removed, the firewall hid port 8000, but `ss` showed the server **still running**. It was killed with `kill 2669`.
- **New finding:** LLMNR (systemd-resolved) is listening on **0.0.0.0:5355 and [::]:5355**. Blocked by ufw, but it's the target of Lab 6.

## 2. Port States (concepts)

| State | What happened | Meaning |
|---|---|---|
| open | Target accepted the connection | A program is listening |
| closed | Target replied "refused" (RST) | Nothing is listening, but the host responds |
| filtered | No reply | A firewall dropped the packet |

## 4. Results

| Test | Tool | Result |
|---|---|---|
| Firewall ON (Parrot default) | nmap | 8000 filtered, even with the server running |
| Firewall OFF | nmap | 8000 open → the firewall caused the filtering |
| 22/80 "filtered" with ufw off | nft + curl | No hidden firewall. curl says **refused**, so iSH's nmap mislabels closed as filtered |
| Firewall ON, port 80 | curl | **Timed out** (refused when off) → really dropped |
| Allow rule (LAN → 8000/tcp) | curl | Served the home folder |
| Rule removed | curl | 8000 timed out |
| Service check | ss | Server still running behind the firewall → killed |

### Final state

| Layer | State |
|---|---|
| ufw | Active. Deny incoming, allow outgoing, routed disabled. **No rules** |
| Listening TCP | systemd-resolved: 127.0.0.53:53, 127.0.0.54:53 (localhost only); **0.0.0.0:5355 and [::]:5355 (LLMNR)** |

## 5. Key Lessons

- **Check the real state, not the assumed default.** ufw was already active.
- **Control comparison:** change one variable (the firewall) and compare the results to prove cause and effect.
- **Verify surprising results with an independent tool.** curl exposed nmap's mislabeling under iSH.
- **Refused vs. timed out** is the practical test for closed vs. filtered.
- **A firewall hides a service, it doesn't remove it.** Check both layers (`ufw status` and `ss -tlpn`).
- **Ad-hoc servers expose more than intended** (`.bash_history`, `.Xauthority`). Serve only a dedicated folder, limit access, and always clean up.
- **Least privilege for firewall rules:** one source network, one port, one protocol.
