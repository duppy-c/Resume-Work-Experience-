## 3. Files Created

### ~/.config/devilspie2/windows.lua

```lua
-- Window layout rules for my Pi lab
local class = get_window_class()
debug_print("Window opened: " .. class)

if class == "firefox" then
  set_window_geometry(554, 40, 804, 614)
end

if class == "qterminal" then
  set_window_geometry(0, 40, 556, 420)
end
```

| Line | Meaning |
|---|---|
| `-- ...` | A comment. Lua ignores it |
| `local class = get_window_class()` | Stores the window's class in a local variable |
| `debug_print(...)` | Prints only when run with `--debug` |
| `if class == "firefox" then` | `==` compares. A single `=` assigns |
| `set_window_geometry(x, y, w, h)` | Moves and resizes the window |
| `end` | Closes each `if` block |

### ~/.config/autostart/devilspie2.desktop

```ini
[Desktop Entry]
Type=Application
Name=Devilspie2
Exec=devilspie2
```

## 4. Open Issue: the nano Ctrl + O Problem

- **Symptom:** Ctrl + O opened Insert File (normally Ctrl + R), and later the Execute Command prompt.
- **Workaround:** save with **Ctrl + X → Y → Enter**, or **Ctrl + S** / **F3**.
- **To investigate:** check nano key bindings (the command is in commands.md), and test the small wireless keyboard vs. the full keyboard.
- **Habit:** read nano's bottom two lines before each key press. They show the current mode.

## 5. Key Lessons

- **Debug-first scripting:** add `debug_print` to see what the script sees.
- **Measure → change → test → adjust.**
- **Verify persistence with a reboot**, then confirm the process with `pgrep`.
- **Security:** autostart folders are a common hiding place for malware. Audit them with `ls -la ~/.config/autostart`.
