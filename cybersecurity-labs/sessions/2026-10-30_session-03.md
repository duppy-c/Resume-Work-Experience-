**Frame = Absolute − Relative.** The window manager places the frame (title bar plus border), not the content area.

**Sanity checks:**
- Firefox right edge: 555 + 804 = 1359. That matches the 1360-pixel-wide screen.
- Terminal right edge: 1 + 556 = 557. Firefox starts at 555, so the windows overlap by 2 pixels.

## 4. Key Lessons

- **Trust On First Use (TOFU):** SSH stores a server's fingerprint on the first connection and warns if it ever changes (a possible man-in-the-middle attack).
- **A lone `-` means "standard input"** for many commands. Use `./-` to mean the file.
- **Spaces separate arguments.** Quote file names with spaces, or use Tab completion.
- **Sanity-check your data:** a 1-pixel-wide window is impossible, so re-read the output.
- **Verify the environment before building:** writing Openbox rules on an xfwm4 system would have silently done nothing.
- **Absolute vs. relative coordinates:** screen position vs. offset inside the window frame.
